Hold a séance with a dead repository.

Necropsy reads an abandoned Git repository and raises a ghost that only knows what was committed before the date you choose. Every claim it makes cites a real commit, and code checks each one.

How it works

  1. ExhumeClone read-only and walk the history: commits, authors, files, churn.
  2. EmbedTurn each commit message into a vector with a local model, stored sorted by date.
  3. Choose a datePick a boundary. Nothing after it is ever retrieved.
  4. AskThe ghost answers from those commits; a verifier deletes claims no commit supports.

Why local

  • Private by default: author emails are stored as hashes only.
  • No per-request cost: after the one-time clone and model downloads, it runs on 127.0.0.1.
  • Swappable models: set NECROPSY_LLM_MODEL to any model Ollama serves.

Honest limits

A warm answer takes tens of seconds to minutes on a CPU-only laptop. The verifier is strict, so refusal is a normal outcome. The ghost is only as good as the commit messages it was given.
