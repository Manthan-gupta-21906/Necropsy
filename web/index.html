Ask a dead repository what it was trying to become.

Necropsy reads an abandoned Git repository and rebuilds a ghost that only knows what was committed before the date you choose. Every claim it makes cites a real commit, checked in code.

How it works

  1. Exhume — Clone read-only and walk the history: commits, authors, files, churn.
  2. Embed — Turn each commit message into a vector with a local embedding model, stored sorted by date.
  3. Choose a date — Pick a boundary. Anything after it is never retrieved.
  4. Ask — The ghost answers from those commits; a verifier deletes claims no commit supports.

Illustrative timeline showing commit history from first to last date.

Why local

  • Private by default — author emails are stored as hashes only.
  • No per-request cost — everything runs on 127.0.0.1 after the one-time clone and model downloads.
  • Swap models — pin the exact checkpoints you trust; override with NECROPSY_LLM_MODEL.
  • After the one-time downloads, the app works with the network disabled.

Honest limits

A warm answer takes tens of seconds to minutes on a CPU‑only laptop. The verifier is strict, so refusal is a normal outcome. The ghost is only as good as the commit messages it was given.
